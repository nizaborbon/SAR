Sistema Administrativo de Reciclaje - Página Informativa

Año del proyecto: 2017

Descripción:
Un equipo de programadores desarrolló un sistema administrativo especializado para la gestión de reciclaje. Fui contratada para crear una página web informativa con el objetivo de dar a conocer su sistema, sus funcionalidades y atraer a posibles clientes interesados en optimizar la administración de sus centros de reciclaje.
El diseño fue ajustado al gusto de los desarrolladores y aprobado por ellos, asegurando que la presentación del sistema reflejara fielmente su visión y objetivos.

Tecnologías utilizadas
* HTML5
* CSS3
* SCSS
* LESS
* Bootstrap
* Javascript

Funcionalidades
* Página de inicio con información general del sistema
* Sección de características clave
* Formulario de contacto

Objetivo:
Facilitar la divulgación del sistema de reciclaje, resaltando sus funcionalidades y beneficios para posibles clientes o usuarios interesados.

-----------------
*Este proyecto está compuesto por archivos estáticos, por lo que no es necesario contar con un servidor o programas adicionales para verlo funcionar. Solo necesitas descargar el repositorio y abrir el archivo index.html en tu navegador preferido.*
